# traffic-analysis
Practice exercise on traffic analysis using Wireshark

Credits: https://malware-traffic-analysis.net/

# Background
My role: SOC analyst

Situation: Someone contacts your team to report a coworker has downloaded a suspicious file after searching for Google Authenticator

Task: To create an incident report using the questions below:
* What is the IP address of the infected Windows client?
* What is the mac address of the infected Windows client?
* What is the host name of the infected Windows client?
* What is the user account name from the infected Windows client?
* What is the likely domain name for the fake Google Authenticator page?
* What are the IP addresses used for C2 servers for this infection?
